# Oracles, Not Org Charts

A single-page, proof-driven manifesto for AI-native engineering. This repo is a
teaching artifact: it turns the "proof over prose" paradigm into a fast, visual,
copy-pasteable experience.

## Live Page
Open `index.html` in a browser.

## Quickstart
- `npm run verify` (runs the repo truth check)
- Open `index.html` to view the site

## Sections (one-screen teaching flow)
1) Phrase: "If it doesn't run, it doesn't exist."
2) Mindset diff (before -> after)
3) One-minute example
4) Funnel illustration
5) Roles -> constraints mapping
6) Control theory lens
7) Paste-ins (AGENTS + project instructions)

## Proof-Driven Assets
- `AGENTS.md` -- drop-in operating rules
- `scripts/verify.sh` -- truth command wrapper
- `scripts/verify.mjs` -- deterministic content checks
